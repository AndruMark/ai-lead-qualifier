# AI-Powered Lead Qualification Widget

An embeddable, real-time AI conversational widget designed to qualify inbound sales leads, extract key intent parameters, and integrate with CRM pipelines.

## Project Overview
This project is developed as the Capstone project for the FlyRank Frontend AI Engineering track. It showcases a modern frontend toolchain, conversational streaming UX, and robust fallback handling.

## Planned Tech Stack
- Framework: Next.js (App Router, React 19)
- Language: TypeScript
- Styling: Tailwind CSS
- AI Interaction: Vercel AI SDK / Streaming API
- Toolchain: Node.js LTS, Git, ESLint, Prettier
